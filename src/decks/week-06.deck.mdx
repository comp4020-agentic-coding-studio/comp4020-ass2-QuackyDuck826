## Getting a reading over serial, step by step

1. Set a baud rate on the board — `Serial.begin(9600)` is a safe
   default — and match it exactly on the receiving code; a mismatch
   doesn't just slow things down, it garbles or drops the message.
2. Print the sensor value as plain, simply-delimited text —
   `Serial.println(value)` — rather than anything more structured, so
   the receiving code only needs to split on that delimiter.
3. Read that stream into the code side: your week 3 creative-coding
   sketch, or the digitizing pipeline from weeks 1–2, picks it up in
   place of a value that used to come from the mouse or the clock.
4. Send something back out to the board — even a computed value into a
   week 5 LED or motor — so the loop is a genuine round trip, not a
   one-way stream of data disappearing into a laptop.
