The first programming pillar, pitched deliberately at the student
cross-training *into* code rather than as a bare general-purpose-language
intro. It's visual and immediate: draw something, change a number, see the
change on screen, in the same second. If you already program, the point of
today is different for you — see below.

## Outline

- a canvas, a draw loop, and a handful of shapes — the whole vocabulary you
  need to start
- variables and simple interactivity: mouse position and time driving what's
  drawn
- for the art-proficient half of the room: this is your on-ramp — go slow,
  lean on what you already know about composition and colour
- for the programming-proficient half: your job this week is mentoring, not
  learning — the depth comes back in Programming II (week 7)
- how this connects back to the digitizing work from weeks 1–2
